1) Yıl Sonu Ortalama ve Harf Notu

2) Finalde Minimum Kaç Lazım?

Kurul notlarını gir → finalden minimum kaç alman gerekiyor gör. Kurul notlarını gir + girmediğin kurullar için 0 yaz → kalan kurullardan kaç alırsan finali 50'ye bırakabiliyorsun gör.

3) Finalsiz Olacak Mı?

Kurul notlarını gir → finalsiz geçebiliyor musun gör. Kurul notlarını gir + girmediğin kurullar için 0 yaz → kalan kurullardan kaç alırsan finalsiz geçebiliyorsun gör.
